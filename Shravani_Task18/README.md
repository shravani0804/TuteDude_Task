# JavaScript Interactive Greeting

In this task, I  have created a simple interactive webpage using HTML, CSS and JavaScript.
I  have added four boxes with different color names.
In this When a box is clicked, JavaScript changes its background color.
I also added an input box to enter the user's name.
When the Greet button is clicked, the heading changes to Hello with the entered name.
I  have used DOM methods to change the text and colors.
